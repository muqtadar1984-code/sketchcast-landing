La explicación

Introduction to Sequences and Term-to-Term Rules

A sequence is an ordered list of numbers that follow a specific pattern or rule. Each number in the sequence is called a term. The position of each term is usually denoted by the letter n, where n represents a positive integer such as 1, 2, 3, and so on. For instance, in the sequence 5, 8, 11, 14, the first term is 5, the second term is 8, the third term is 11, and the fourth term is 14. Understanding sequences requires examining how numbers relate to one another as the list progresses.

The most basic way to describe a sequence is through a term-to-term rule. A term-to-term rule explains how to get from one term to the next term in the sequence. For example, consider the sequence 3, 6, 12, 24. To move from 3 to 6, one multiplies by 2. To move from 6 to 12, one also multiplies by 2. The term-to-term rule for this sequence is 'multiply by 2'. Another example is 20, 17, 14, 11, where the term-to-term rule is 'subtract 3'. While term-to-term rules are intuitive and easy to calculate, they have a significant limitation: to find the hundredth term using a term-to-term rule, one must calculate the first ninety-nine terms beforehand. This limitation necessitates the use of position-to-term rules and nth term formulae.

Position-to-Term Rules

A position-to-term rule connects the position of a term, represented by n, directly to the value of the term itself, without needing any previous terms. This allows anyone to jump straight to any term in the sequence, no matter how far along it is. Imagine a table where the top row is the position n (1, 2, 3, 4) and the bottom row is the corresponding term value. Consider the sequence 4, 7, 10, 13. When n equals 1, the term is 4. When n equals 2, the term is 7. When n equals 3, the term is 10. Analysing the relationship between n and the term reveals that multiplying the position number n by 3 and then adding 1 gives the exact term value. Testing this rule: for n equals 1, 3 times 1 plus 1 equals 4. For n equals 2, 3 times 2 plus 1 equals 7. For n equals 3, 3 times 3 plus 1 equals 10. The algebraic expression for this position-to-term rule is 3n + 1. This algebraic expression is known as the nth term of the sequence. Position-to-term rules can involve addition, subtraction, multiplication, and division, and they form the foundation of linear algebra in lower-secondary mathematics.

Finding the nth Term of Linear Arithmetic Sequences

An arithmetic sequence, sometimes called an arithmetic progression, is a sequence in which the difference between any two consecutive terms is always the same. This constant difference is called the common difference. The sequence 7, 11, 15, 19 is a linear arithmetic sequence because the difference between consecutive terms is always 4. Finding the nth term formula for any linear arithmetic sequence follows a reliable two-step method.

Step one: find the common difference. Subtract any term from the term that immediately follows it. In the sequence 7, 11, 15, 19, subtracting 7 from 11 gives 4. This common difference tells the investigator the coefficient of n in the formula. Therefore, the formula starts with 4n. Step two: generate the first few terms of the 4n sequence and compare them to the actual sequence. The 4n sequence generates 4, 8, 12, 16, while the actual sequence is 7, 11, 15, 19. Comparing term by term, every number in the actual sequence is exactly 3 greater than the corresponding number in the 4n sequence. Therefore, the complete nth term formula is 4n + 3. This method works for any linear arithmetic sequence. If the common difference is negative, such as in the sequence 10, 7, 4, 1, the common difference is minus 3. The formula starts with -3n. Generating the sequence -3n gives -3, -6, -9, -12. Comparing this to 10, 7, 4, 1, the adjustment required is adding 13, because -3 plus 13 equals 10. Thus, the nth term is -3n + 13.

Generating Terms and Testing Values

Once an nth term formula is established, it can be used to generate any term in the sequence by substituting values for n. For instance, to find the fiftieth term of the sequence with the nth term formula 5n - 2, one substitutes 50 in place of n. Calculating 5 times 50 gives 250, and subtracting 2 gives 248. The fiftieth term is 248. This substitution process eliminates the tedious work of writing out all preceding terms.

Furthermore, an nth term formula allows mathematicians to test whether a specific number belongs to a sequence. To test if a number is part of a sequence, set the nth term formula equal to that number and solve the resulting linear equation for n. If the resulting value of n is a positive integer, meaning a whole number greater than zero, then the number is in the sequence and the value of n gives its exact position. If n is a fraction, a decimal, zero, or a negative number, the tested number does not belong to the sequence. For example, to check if 100 belongs to the sequence with the nth term 4n + 3, set 4n + 3 equal to 100. Subtracting 3 from both sides gives 4n equals 97. Dividing by 4 gives n equals 24.25. Since 24.25 is not a whole number, 100 is not a term in the sequence 4n + 3. Testing numbers in this way provides a rigorous mathematical proof for the composition of number patterns.

Common Mistakes and How to Avoid Them

Learners studying sequences frequently encounter specific pitfalls that lead to incorrect answers. Being aware of these errors helps prevent them during problem-solving. One frequent mistake is confusing the term-to-term rule with the position-to-term rule. When asked for the nth term of 5, 8, 11, 14, a learner might write 'plus 3' instead of '3n + 2'. The term-to-term rule describes how the sequence changes, whereas the nth term is an algebraic expression involving n. The response to a request for the nth term must always contain the variable n.

Another common error occurs when finding the adjustment value for the nth term formula. After finding the common difference, such as 5 for the sequence 5n, learners often miscalculate the number needed to adjust the first term. For the sequence 9, 14, 19, 24, the common difference is 5, giving 5n. The first term generated by 5n is 5. To get from 5 to 9, one must add 4, making the formula 5n + 4. A common mistake is subtracting 4 because the learner focuses on the difference between 9 and 5 in the wrong direction. Always check the formula by substituting n equals 1, 2, and 3 to ensure the generated terms match the original sequence.

A third error happens when testing whether a number belongs to a sequence. When solving the equation for n, learners sometimes accept a decimal or fractional answer as proof that the number is in the sequence, simply because the equation was solved successfully. It is essential to remember that position numbers must be positive integers. A fractional position value means the number falls between two terms and therefore does not belong to the sequence.

Términos clave

Sequence
An ordered list of numbers that follow a specific mathematical rule or pattern.
Term
A single number or value within a sequence.
Term-to-term rule
A rule that explains how to calculate the next term in a sequence using the preceding term.
Position-to-term rule
A rule that connects the position number of a term directly to its value without needing previous terms.
Arithmetic sequence
A sequence in which the difference between any two consecutive terms is always constant.
Common difference
The constant difference between consecutive terms in an arithmetic sequence.
Nth term
An algebraic expression that defines the position-to-term rule for any term in a sequence.

Ejemplos resueltos

1Find the nth term formula for the linear sequence 6, 10, 14, 18, and calculate its 40th term.

Mostrar la solución

Step 1: Find the common difference by subtracting consecutive terms. 10 - 6 = 4, 14 - 10 = 4, 18 - 14 = 4. The common difference is 4, so the formula starts with 4n.

Step 2: Generate the first term of 4n by substituting n = 1. 4(1) = 4.

Step 3: Compare this to the first term of the actual sequence, which is 6. To get from 4 to 6, add 2.

Step 4: Combine these to write the nth term formula: 4n + 2.

Step 5: Calculate the 40th term by substituting n = 40 into the formula. 4(40) + 2 = 160 + 2 = 162. The 40th term is 162.

2Determine whether the number 85 is a term in the sequence given by the nth term formula 3n + 5.

Mostrar la solución

Step 1: Set the nth term formula equal to the number in question: 3n + 5 = 85.

Step 2: Solve the linear equation for n. Subtract 5 from both sides: 3n = 80.

Step 3: Divide both sides by 3: n = 80 / 3 = 26.666...

Step 4: Evaluate the result. Since 26.666... is not a positive integer (whole number), the number 85 is not a term in the sequence 3n + 5.

Ideas erróneas frecuentes

Error común Believing that writing 'add 4' is a correct answer for finding the nth term of a sequence.

En realidad The phrase 'add 4' is a term-to-term rule, not an nth term. The nth term must be an algebraic expression containing the variable n, such as 4n + 1.

Error común Assuming that the common difference itself is the entire nth term formula.

En realidad The common difference only provides the coefficient of n. An adjustment number is almost always required to complete the nth term formula.

Error común Thinking that any number that fits an equation when solved for n belongs to the sequence, even if n is a decimal.

En realidad Position numbers n must always be positive integers. If solving for n yields a decimal or fraction, the number does not belong to the sequence.

Error común Subtracting the first term of the sequence from the common difference when finding the adjustment value.

En realidad The adjustment is found by taking the first term of the sequence and subtracting the value generated by substituting n equals 1 into the coefficient term.
